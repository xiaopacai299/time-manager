页面监听扩展 · 配置

在 Chrome 打开「扩展程序 → 本扩展 → 详细信息 → 扩展程序选项」即可回到此页。加载方式：开发者模式 → 加载已解压的扩展程序 → 选择仓库内 packages/chrome-extension 目录。

请先聚焦在要抓取的普通网页标签页上，再按快捷键。若按键完全无反应，请打开 chrome://extensions/shortcuts 确认「Time Manager 页面监听」已绑定快捷键且未被占用。扩展使用普通 JSON调用 AI（非流式），正文入模前会截断，一般不是「数据太大」等问题。
与手机登录页填写的地址一致（不要带末尾斜杠）。
长期有效；泄漏后请在 App 内吊销并重新生成。请求头仍使用 Authorization: Bearer <密钥>。
任意合法 UUID 即可（扩展会用该请求头发给服务端）；点按钮可随机生成。
填到版本路径即可，扩展会自动接 /chat/completions。例如 OpenAI 用 https://api.openai.com/v1；若厂商文档给的是已含 …/chat/completions 的完整 URL，也可整条粘贴，不会重复拼接。
