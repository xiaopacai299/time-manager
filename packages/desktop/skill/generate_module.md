## 写新功能模块中的说明文档

当我在对话中说“写一个xxx功能”时，请按以下内容执行：
- 要将这个功能模块尽可能的封装城独立的组件或者文件，然后引入到主文件当中，保持工程结构的清晰
- 对于重要的逻辑和关键的逻辑写注释
- 生成组件的时候，在src/components的文件夹下，建立新的文件夹，然后将组件和对应的样式放入到文件夹中，而不是直接将文件放在components中

## 页面文案

开发或迭代 UI 功能后：
- 不要在页面上增加额外的引导、说明段落（例如「点击 xx 可…」「按 xx 划分…」类副标题或提示条）
- 用标题、字段 label、按钮与空状态等既有控件表达即可；确有必要时优先用 `title`/`aria-label`，而非长段说明文字
