# UI 设计语言（桌面端 · 每次改 UI 必读）

开发或调整 `packages/desktop` 界面时，**先阅读本文件**，与 `generate_module.md` 一并遵守。

## 核心原则

- **用设计语言表达功能**：颜色分区、坐标轴、图标、徽标、圆点状态、悬浮显隐、布局位置
- **少用长文案**：不写引导段、不在卡片上堆字段名（如「提醒时间：」）；必要信息用 `title` / `aria-label`
- **状态要像状态**：圆点 + 短标签色块（pill），进行中可动效，完成/未完/待办一眼可辨
- **危险操作低调**：删除等仅在 hover / focus-within 时显示图标按钮

## 四象限 / 矩阵类

- 外框 + 十字分割线 + 行/列轴标签（重要/不重要 × 紧急/不紧急）
- 象限用背景色区分；角标用短词或数字，完整含义放 `title`
- 空区用符号（如 `—`），不用「暂无 xxx」长句
- 添加入口放在对应象限内（如 `+`），自动带上该象限字段，不在表单重复选择

## 列表卡片

- 默认一行：图标 + 标题 + 状态 pill +（悬浮）操作
- 次要信息（备注）单行省略，无则省略块
- 不在卡片展示用户已在别处配置的细项（如提醒/预计完成时间），编辑弹窗中再管

## 与文案规范的关系

见 `generate_module.md` 的「页面文案」：两者同时生效，冲突时优先 **少字 + 多视觉**。
