天气图标方案预览

以下为开源图标库多种风格对比（非 AI 生成图）。请在本页查看后，回复要采用的方案，例如： 「全部用 C」、「晴/多云用 C，雨用 A」 或 「继续优化 A」。 点击某一格可高亮选中（仅本地记录，方便你对照）。

A现用：Lucide 叠层（黄太阳 / 白云 / 蓝雨） BLucide 单体（CloudSun、CloudRain 等） CBasmilius Weather Icons 彩色填充（MIT） DTabler Icons 描边（MIT） EPhosphor Icons 双色（MIT）
打开方式：在资源管理器中双击本文件，或在终端执行 pnpm --filter @time-manger/desktop run preview:weather-icons

图库说明

  • Lucide — 当前项目已安装
  • Basmilius Weather Icons — 彩色、辨识度高
  • Tabler Icons
  • Phosphor Icons
