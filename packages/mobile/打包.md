# 移动端打包（Expo Go 开发 + EAS 云端出包）

日常用 **Expo Go**；要 **APK / AAB** 时用 **EAS Build（线上打包）**。配置在 **`packages/mobile`**（`app.json`、`eas.json`）。

---

## 日常开发（Expo Go）

```powershell
cd D:\work\time-manager
pnpm run mobile:start
```

用 Expo Go 扫终端二维码（**默认局域网**，手机与电脑需同一 Wi-Fi）。若跨网络再试根目录 **`pnpm run mobile:start:tunnel`**（依赖 ngrok，国内易失败）。**API 地址不再在登录页填写**：开发环境由 **`packages/mobile/.env.development`** 的 `EXPO_PUBLIC_API_BASE` 决定（真机连本机请改为 `http://电脑局域网IP:3000`）；安装包由 **`eas.json`** 构建时注入（如公网服务器）。

---

## 首次云端打包前（只做一次）

1. 注册 [expo.dev](https://expo.dev) 账号。  
2. 安装并登录 EAS CLI（推荐全局，少踩 Windows 锁文件问题）：

```powershell
npm install -g eas-cli
cd D:\work\time-manager\packages\mobile
eas login
eas build:configure
```

`build:configure` 会生成/更新 **`eas.json`**，并在 **`app.json`** 写入 **`extra.eas.projectId`**，勿删。生产 API 等环境变量以 **`eas.json`** / **`.env.production`** 为准，改域名后需重新构建安装包。

---

## 发起线上构建

在 **`packages/mobile`** 已 `eas login` 的前提下：

| 产物 | 命令（在仓库根目录） |
|------|----------------------|
| Android **AAB**（上架 Play） | `pnpm run mobile:build:android` |
| Android **APK**（内测直装） | `pnpm run mobile:build:android:apk` |
| **iOS** | `pnpm run mobile:build:ios` |

或在 **`packages/mobile`** 下：`pnpm run build:android` / `build:android:apk` / `build:ios`。  
等价：`eas build -p android --profile production`（AAB）、`--profile preview`（APK）。

完成后在终端或 [expo.dev](https://expo.dev) 项目页 **下载安装包**。

---

## 可选说明

- **Monorepo 云端报错找不到 workspace 包**：在 `eas.json` 对应 profile 的 `env` 中加 `"EXPO_USE_METRO_WORKSPACE_ROOT": "1"`（以 [Expo Monorepo](https://docs.expo.dev/guides/monorepos/) 为准）。  
- **独立包访问 HTTP**：Android 已 `usesCleartextTraffic`；iOS 依赖 `app.json` 里局域网明文配置，改后需 **重新 EAS Build** 才进包。  
- **不走本地 Gradle / Xcode**：若以后需要离线改原生，再查 `expo prebuild` + Android Studio；当前流程可忽略。
