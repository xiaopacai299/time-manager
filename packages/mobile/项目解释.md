# metro
相当于普通项目的vite或者webpack，在metro.config.js中配置

# expo
开发客户端部分，构建发布，以及开箱即用的api如相机，推送等，在app.json中配置

# 使用的标签
View、Text、TouchableOpacity 等，用 StyleSheet / flex

# 鉴权相关内容
在最外层套一个AuthProvider鉴权层（这个是逻辑层，没有ui，也是react聪明的地方），在此阶段判断用户是否登录，并且向外提供useAuth({ auth, login, logout })供外界使用，一、RootNavigator中使用auth.status来决定展示哪个页面   二、在登录页面，使用login，logout来完成登录或者不登陆
```
{/* 认证提供者 */}
        <AuthProvider>
          {/* 状态栏 */}
          <StatusBar style="dark" />
          {/* 根导航器 */}
          <RootNavigator />
        </AuthProvider>
```
